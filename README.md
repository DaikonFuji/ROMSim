# ROM Skill Simulator (English)

An English skill simulator for Ragnarok Mobile: Eternal Love.

**Live site:** https://daikonfuji.github.io/ROMSim/

## Classes

- Swordsman: Rune Knight, Royal Guard
- Mage: Warlock
- Thief: Guillotine Cross, Shadow Chaser
- Archer: Ranger
- Acolyte: Arch Bishop, Shura
- Merchant: Mechanic, Genetic
- Homunculus: Lif, Amistr, Vanilmirth

Each class includes its full job path, for example Acolyte → Monk → Champion → Shura.

## Using it

- Pick a class from the dropdown. Each class has its own link, such as `https://daikonfuji.github.io/ROMSim/#shura`.
- Click **+** / **−** to spend points, **▲** to max a skill, or hold Shift and click **−** to clear one.
- Hover over or tap a skill to see its effect at the current and next level.
- **Share / load build** gives you a build code. Codes work with the original [ROMEL Skill Simulator](https://romelde.github.io/SkillSimulator/), and you can paste a link from that site to load the build here.
